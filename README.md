# TpPortfolio
Realizado en Angular 21.

## Requerimientos
Node.js 22 o superior y una versión de npm compatible

## Instrucciones
1. Clonar
2. `npm install`
3. `npm start`
4. Abrir la URL que se muestra en la terminal ([http://localhost:4200](http://localhost:4200) salvo que ese puerto ya esté en uso)
